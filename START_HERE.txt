START HERE — Predictive Maintenance ML Project

1. Extract this ZIP.
2. Open the Predictive-Maintenance-ML folder in VS Code.
3. In the VS Code terminal, run:
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
4. Train the models:
   python src/train_model.py
   (First run downloads the UCI AI4I dataset. Internet is needed.)
5. Start the dashboard:
   python -m streamlit run app.py
6. Report and presentation are in the reports folder.
7. IMPORTANT: The report deliberately does not invent results. After training, copy the real metrics from outputs/model_comparison.csv into the Results section/slides before submitting.

If PowerShell blocks activation, use Command Prompt:
   .venv\Scripts\activate.bat

Official dataset: https://archive.ics.uci.edu/dataset/601/ai4i
